Work log

Current work is tracked in the project’s public GitHub issues, which provide the most up-to-date view of ongoing tasks, discussions, and milestones.

This monthly diary is a reverse-chronological summary of the project’s work as recorded in the public GitHub issue tracker. The most recent month is expanded in more detail, while earlier work is retained as context. There is also a forward-looking section for milestones on the horizon.

October 2026

Current focus

  • Finalisation of the roadmap and project narrative around the core infrastructure, publication, and data workstreams.
  • Consolidation of the issue backlog into a more stable development sequence for the next implementation phase.
  • Preparation of the project’s public-facing documentation and notice set in parallel with technical progress.

Detailed notes

  • The project roadmap is now centred on the issue-based milestones captured in Issue #236, with particular emphasis on locking down the ER model, common schemas, glossary terms, citations, and data coverage.
  • The project continues to operate as a structured publication and knowledge-infrastructure effort rather than a single linear software build.
  • Current work is focused on turning the early prototype work into a more coherent and stable delivery path.

On the horizon

  • Complete and stabilise the ER model.
  • Finish the remaining glossary and citation data.
  • Add the missing data sources and WG1 figure assets.
  • Progress from prototype publication workflows to a more production-ready deployment path.

September 2026

  • Project documentation and public notices were expanded to align with the project’s institutional and external-facing narrative.
  • The work progressed from prototype-driven development toward a clearer roadmap and publication-oriented structure.
