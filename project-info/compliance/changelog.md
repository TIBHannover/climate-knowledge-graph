# Change log

## English

This change log records material updates to the ClimateKG project, its documentation, public notices, and related digital resources. It is intended to support transparency, traceability, and version awareness for project stakeholders.

### Format
Entries may include:
- date
- summary of change
- affected document, service, or repository component
- relevant issue, milestone, or release reference

### Current status
This document is maintained as a living record. For the latest operational details, please consult the project repository, release pages, and relevant website sections.
