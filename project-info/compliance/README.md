# Compliance source documents

This folder contains source templates for the ClimateKG public policy and compliance notices. They are intended to be reusable across the project’s websites and Git repositories.

## Included documents
- About us
- Our publications
- Roadmap
- Change log
- Imprint
- Data protection
- Terms of use
- Accessibility

## Notes
- These source documents are maintained in Markdown for ease of reuse and adaptation.
- The content is written as a TIB-aligned baseline and should be reviewed by the responsible institutional contact before final publication.
- Exact legal and institutional details such as addresses, contact points, and repository policies may require confirmation before release on public-facing services.

## Intended use
These templates can be adapted for:
- website pages
- GitHub and GitLab notices
- project landing pages
- public repository documentation
